# Marketing Site UI Kit

RTL-first recreation of the Bedar public website (reference: https://bedar.webflow.io/).

Surfaces included:
- **Home** (`index.html`) — hero, services grid, programs (dark section), testimonials, footer.

All content strings are Arabic to match the live site. Every block on this page is a candidate for CMS-driven mapping via the schemas documented in `/components/blocks/*.prompt.md`.
