# Admin Dashboard UI Kit

Headless-CMS-style admin where non-technical admins compose pages from schema-defined blocks.

Surfaces:
- **Page Builder** (`index.html`) — 3-pane: block list · live canvas · schema-driven inspector.
- **Applicants** (`applicants.html`) — filterable table with tags, status badges, bulk actions.

Every inspector field maps 1:1 to a JSON key in the CMS payload, so admins never touch code.
